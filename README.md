# Silk Road — History Project

Standalone history website with a scrollable timeline, interactive maps, photographs, sources, animations, and light/dark themes. No Orbit, chat, games, authentication, Morse-code entry, or Supabase dependency is included.

Run `npm ci`, then `npm start`. Open http://localhost:3000.

On Render, connect this repository with build command `npm ci && npm run build` and start command `npm start`, or use render.yaml. Leave Root Directory empty.

Image credits are displayed on the website and listed in silk-road/SOURCES.txt. Font licenses are retained in silk-road/fonts/.
